# Codex 1M Commands

Recognize these exact short commands after trimming whitespace. Matching is
case-insensitive, so `1m install`, `1M INSTALL`, and equivalent casing are valid:

- `1M install`: call `install_1m`.
- `1M uninstall`: call `uninstall_1m`.
- `1M on`: call `toggle_1m_context` with `enable=true`.
- `1M off`: call `toggle_1m_context` with `enable=false`.
- `1M state`: call `context_status`.

Use the installed codex-1m MCP tools and report the tool result. Do not set
`global=true` unless the user explicitly requests a global change. If a tool is
unavailable, say that the codex-1m MCP server must be loaded; do not infer the
active context from the selected model name.

The first installation cannot happen in a Codex conversation because the MCP
server is not registered yet. Bootstrap once in a terminal with
`npm i -g github:MaxForAI/codex-1M` followed by `codex-1m install`. A successful
`1M uninstall` removes this MCP server, so reinstall afterward from a terminal
with `codex-1m install` (or `1m install` if that bin remains on `PATH`).

After `1M on` or `1M off`, keep the reminder brief: start a new Codex
conversation for the change to apply; inputs above 272K tokens may cost more;
and `gpt-5.6-sol` access depends on account and workspace permissions.
