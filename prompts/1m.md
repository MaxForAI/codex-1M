# 1M Context Status

Call the installed `context_status` MCP tool and report its result. Do not
modify configuration unless the user explicitly asks to enable or disable it.
If the tool is unavailable, explain that codex-1m's MCP server must be
registered; do not guess the active context from the selected model name.

Remind the user that a config change only applies to a newly created Codex
chat/session. See `docs/gui-integration.md` for GUI options and caveats.
